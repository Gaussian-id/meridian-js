# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. The report goes to the repository owner.

Include the affected package and version, what you observed, and the smallest steps that reproduce it. Never include a live `gmr_` or `gmi_` key in a report; redact it.

You will get an acknowledgement, and a fix or an assessment will follow as soon as it can be made. Please give us a reasonable time to ship a fix before you disclose the issue publicly.

## Supported versions

This is a public preview (v0.1.x). Only the latest published version receives security fixes.
